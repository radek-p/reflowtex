Two forms: inline {{< latex >}} $e^{i\pi} + 1 = 0$ {{< /latex >}} file ref {{< latex file="01-inline-math.tex" />}} (self-closing) The file ref points at a shared .tex source (resolved by prebuild.py against its --demos-dir), so the same snippet can feed several integrations. prebuild records file→key in hugo.Data.latex_files; the inline form is hashed here. An inline block can register in that same lookup with as="name" instead — for a snippet with no natural .tex file of its own (a page's short title, a handful of one-line labels a sidebar looks up from every page, …) that another template wants to find later by name, without a --demos-dir entry per snippet. See prebuild.py's module docstring. Optional attributes (all forwarded to latex-viewer.js as data-* on the block): preamble="name" use latex-preambles/name.tex (inline form; also hashed) as="name" inline form only: also register under this name in hugo.Data.latex_files, as if it were a file="name" ref color-map="name" use latex-color-maps/name.json (see prebuild.py); does not affect compilation, so file refs need it repeated per shortcode call the same as any other data-* option.
