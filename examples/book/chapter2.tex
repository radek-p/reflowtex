\chapter{Sums}
This chapter is compiled together with the first one, so it can use
$\N$, which chapter~1 defined, and refer back to it: by
Theorem~\ref{thm:induction}, equation~\eqref{eq:gauss} holds for every
$n \in \N$.\footnote{The induction step adds $n+1$ to both sides.}
\begin{theorem}\label{thm:squares}
For every $n \in \N$,
\[ 0^2 + 1^2 + \dots + n^2 = \frac{n(n+1)(2n+1)}{6}. \]
\end{theorem}
Its number continues the book's own count: chapter~2, first theorem.
