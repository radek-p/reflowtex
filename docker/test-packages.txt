# TeX Live packages the tests' documents load beyond what the Dockerfile's
# own list installs (the pipeline's needs): the render, capture, web and unit
# suites' fixtures, and the website's pages. Installed when the image is
# built (the Dockerfile reads this file), so a test run fetches nothing: the
# tests turn the lualatex wrapper's install on demand off
# (REFLOWTEX_NO_AUTOINSTALL), and a package missing from here fails with a
# message that names this file. One tlmgr package per line; # starts a comment.
#
# Found by running every suite and `make website` in a fresh image with
# REFLOWTEX_NO_AUTOINSTALL=0 REFLOWTEX_AUTOINSTALL_LOG=<file> (CONTRIBUTING.md, "CI").
nicematrix      # tests/render/cases/nicematrix.tex; the website's Pictures page
pgfplots        # tests/render/cases/tikz-nested.tex; examples/demo/figures (the web tests' and the website's pages)
transparent     # tests/capture/capture.test.ts (colours and opacity)
newtx           # tests/capture/capture.test.ts (virtual fonts: newtx maths); with the next five, what newtxtext and newtxmath load
txfonts         # newtxmath's symbols (txsyc)
kastrup         # newtx (binhex.tex)
xpatch          # newtx
xkeyval         # newtx
xstring         # newtx
charter         # tests/unit/type1.test.ts (Bitstream Charter's Type 1 outlines)
bbm             # tests/render/cases/bbm.tex: METAFONT-only fonts (src/pipeline/fonts/metafont.ts)
bbm-macros      # bbm.sty, for the same case
float           # tests/render/cases/floats.tex, tests/capture/capture.test.ts (floats in the flow): \newfloat, [H]
algorithms      # the same: algorithm.sty's ruled float
newfloat        # tests/capture/capture.test.ts (floats in the flow): \DeclareFloatingEnvironment
times           # tests/render/cases/times-microtype.tex: T1 Times through its virtual fonts (psnfss's times)
tocloft         # tests/render/cases/leaders.tex: a table of contents whose entries keep their dot leaders
