% Paragraphs ending in \index entries, a \label or a \special after the last
% word, as in books and manuals. Each is a whatsit, which TeX's line breaker
% keeps: the space after the last word is then a breakpoint whose discards
% stop at the whatsit, and a break there leaves an empty last line that keeps
% its \parfillskip. When the text nearly fills the line, so that the trailing
% space would make it overfull, TeX takes that break: the word's line is
% justified and an empty line follows. Each paragraph leaves 0 to 6.5 pt at
% its line's end; a rule below each shows where the next item starts.
\documentclass{article}
\usepackage{makeidx}
