\begin{itemize}
\item The class has bounded tree-depth and is closed under taking minors and subgraphs.\hfill [Gaj+20, Thm.~1.4]
\item The class has bounded tree-width and is closed under taking minors.\hfill [CO00, Cor.~2.1]
\item The class has bounded expansion and is weakly sparse in the usual sense.\hfill [Tor23, Thm.~3]
\item The class is nowhere dense and is closed under taking subgraphs.\hfill [Dvo18, Lem.~5.2]
\item The class has bounded degree and bounded tree-width at once.\hfill [Gaj+20, Prop.~2]
\end{itemize}
