\begin{theorem}[{[DT25, Cor.~1.8]}]
A graph class has bounded expansion if and only if it is weakly sparse and
has bounded merge-width, and then its strong colouring numbers are bounded
by a function of the merge-width, which is computable, and every class of
bounded expansion is weakly sparse and has bounded merge-width at every
radius, as was shown before by other means.
\end{theorem}
