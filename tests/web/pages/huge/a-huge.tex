  like the logarithm of the number of terms, and part \the\hugen{} says so
  again at some length, with $\sum_{n \le N} 1/n = \ln N + \gamma + O(1/N)$

  and a paragraph of this length takes several lines even on a wide screen.
  \[ \sum_{k=1}^{\the\hugen} k = \frac{\the\hugen\,(\the\hugen+1)}{2}
     \qquad\text{and}\qquad \int_0^1 x^{\the\hugen}\,dx = \frac{1}{\the\hugen+1}. \]

  ends part \the\hugen{} with a reference to the next one.
