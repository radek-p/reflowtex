% Paragraphs that end in negative glue, as \hspace{-1cm} before a blank line
% sets it: TeX drops a start as soon as a line from it is overfull, in every
% pass, so the last line's negative glue never lets an earlier start reach the
% end. Each paragraph is set at several measures. Captured with capture.lua
