% Paragraphs that end in negative glue, as \hspace{-1cm} before a blank line
% sets it: TeX drops a start as soon as a line from it is overfull, in every
% pass, so the last line's negative glue never lets an earlier start reach the
% end; and a break at that glue leaves an empty last line without the
% \parfillskip's stretch, which TeX takes only when nothing else is left
% (after \\ or \break at a paragraph's end too). Each paragraph is set at
% several measures. Captured with capture.lua into negative-glue/ (README.md).
